CLASS DISCUSSION

Explain what changes.

Use the slides to support your answer. Suggested answers are starting points for discussion.

Slide 18 →

Discussion: training or sampling?

  • Training on a new image set: which values change?
  • Generating with a new seed: which values change?
  • Which action can change learned subject behavior?
Suggested answer

Training changes the model weights. A new seed changes random choices during generation; it usually leaves the weights fixed. Training or adaptation can change learned subject behavior.

Slide 38 →

Discussion 2: Does it match the instructions?

  • Goal: yellow coat, red suitcase on the left, station roof on the right.
  • list the details you would check.
  • could the picture look good and still get these details wrong?
Suggested answer

Check the yellow coat, the red suitcase and its position, and the station roof on the right. A picture can have pleasing color and composition while placing an object incorrectly.

Slide 58 →

Discussion 3: Clear subject, wrong mood

  • The coat is yellow, but the picture feels harsh and crowded.
  • how would you compare guidance settings fairly?
  • how would you judge the colors and mood?
Suggested answer

Compare the same seeds at several guidance values while keeping other settings fixed. Judge crowding, color saturation, lightness, and the intended mood across the grid.

Slide 89 →

Discussion: Design an experience that responds

  • Imagine a visitor moves the red suitcase in our station scene.
  • Should the system explain, predict a new scene, or move a real prop?
  • What should happen if it misunderstands the visitor?
Suggested answer

Choose the output the experience needs: an explanation, a predicted scene, or a physical action. If it is uncertain about the visitor’s intention, the system should ask or stop before moving a real prop. Test both correct responses and misunderstandings.

Slide 93 →

Discussion 4: Compare the pictures

  • Compare the pictures. Which differences seem related to the settings, and which might come from the seed?
Suggested answer

Compare matched seeds across settings. Judge the same visible features in each picture, including object placement, color, and composition. Use several seeds to see whether a difference is consistent.

Slide 95 →

Discussion 5: Choose a look for our scene

  • choose a camera view and drawing style for our scene.
  • explain your choice using two details in the pictures.
  • name one change you would try next.
Suggested answer

Choose a view and style, then point to two visible details that support the choice, such as the suitcase silhouette and the separation between the visitor and the roof. Name one setting or local edit to change next.

Slide 96 →

Three questions before we finish

  • Why can the same prompt give different pictures?
  • Why might stronger guidance make the picture worse?
  • What would you save so you can repeat a result?
Suggested answer

Different seeds produce different starting noise. Very strong guidance can damage color, detail, or variety. Save the prompt, negative prompt if used, model version, seed, sampler, step count, guidance, resolution, and any reference images or masks.
