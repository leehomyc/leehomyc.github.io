CLASS DISCUSSION

Explain what changes.

Use the slides to support your answer. Suggested answers are starting points for discussion.

Slide 18 →

Training and sampling

When does the model change its weights, and when does it use those weights to make an image?

Suggested answer

Training adjusts weights using examples and a loss. Sampling uses the trained weights to update an image representation. A usual generation run does not retrain the model.

Slide 38 →

Words and visual relationships

A prompt names a red bowl beside a blue cup. What would you check in the output?

Suggested answer

Check whether each color belongs to the right object and whether the spatial relationship is correct. Listing the requested objects is only part of following the prompt.

Slide 58 →

Guidance and mood

If stronger guidance makes a poster more literal but less subtle, which result would you choose?

Suggested answer

Compare both against the intended mood, hierarchy, color, and texture. Stronger prompt matching can help some decisions while harming others. Keep seeds and other settings fixed when testing guidance.

Slide 89 →

An interactive artwork

What must you test before connecting a model to an installation that moves physical objects?

Suggested answer

Test the actual action, including position error, missed detections, delays, and stopping behavior. A plausible description or predicted video does not establish reliable physical execution.

Slide 93 →

Compare the outputs

How would you separate a guidance effect from one lucky seed?

Suggested answer

Use the same set of seeds at each guidance value, hold other settings fixed, and judge the same visual features across the whole grid.

Slide 95 →

Choose a direction

Which image best supports an exhibition poster, and what would you change next?

Suggested answer

State a concrete criterion such as space for type, clear object silhouette, or a quiet color relationship. Choose a result using that criterion, then identify one local change to test.

Reading 1

We Must Pace the Frontier ↗

Dario Amodei · September 2026

Amodei argues that AI capability should advance slowly enough for safeguards to catch up. Consider his proposals for independent evaluation and coordination, and what evidence would justify slowing development.
