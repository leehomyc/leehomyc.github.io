# Languages

Five languages: 简体 `zh` · 繁體 `zt` · English `en` · 日本語 `ja` · 한국어 `ko`.

- Game code keeps writing `L('简体','English')` and content objects with `zh/en` and `d/de`. Nothing else changes for new text.
- `js/i18n.js` turns that into the player's language:
  - 繁體 is converted from 简体 at runtime with `i18n/zt.js` (character map + phrase fixes, built by `tools/i18n/build_zt.py` from OpenCC s2tw plus a game vocabulary list).
  - 日本語 / 한국어 look up the **English** text in `i18n/ja.js` / `i18n/ko.js`. Keys with `{0}` `{1}` are templates; captured pieces (skill names inside sentences) are translated again. Lines joined with ` · `, `/`, ` + ` and `Name +12%` are split and translated piece by piece.
  - Missing Japanese/Korean lines fall back to English and are listed in `I18N.miss` in the browser console.
- Style: plain, friendly game words that players everywhere know (Brawl Stars / Torchlight feel). No 江湖 or heavy wuxia jargon in UI/system words. `tools/i18n/terms.py` enforces the vocabulary (skills, mana, relics, missions, ascension…) and a friendly tone on every Japanese/Korean line.

## Adding text

1. Write `L('简体','English')` as usual.
2. `cd tools/i18n && npm i acorn acorn-walk puppeteer-core && pip install opencc`
3. `node leftovers.mjs ../..` lists English strings with no Japanese/Korean line yet. Add them to a new `tr/extraN.json` as `[["English","日本語","한국어"], …]`.
4. `python3 build_i18n.py ../.. tr/extra1.json tr/extra2.json tr/names.json tr/extraN.json` rebuilds `i18n/ja.js` and `i18n/ko.js`; `python3 build_zt.py ../..` rebuilds `i18n/zt.js` when Chinese text changed.
5. `node check.mjs http://localhost:8000/spell-legion/ /tmp/shots ja,ko` plays menus, cards, boss, pause, results and a duel in each language and reports untranslated strings.
